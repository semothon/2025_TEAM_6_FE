# 📖 강의실 대여 플랫폼

> > 예약은 간단히, 모임은 완벽하게!

### 비대면 혁신 & 디지털 전환

[문제정의] 강의실을 대여하기 위해서는 행정실에 직접 방문하여 대여 가능한 강의실이 있는지 담당자를 직접 만나야만 확인이 가능했으며, 수기로 똑같은 대여 신청서를 2장 작성 후 담당자의 서명까지 필요로 했다.

[해결방안] <strong> 온라인으로 신청부터 승인까지 가능하도록 비대면 시스템 구축. </strong>
해당 시스템을 통해 행정실의 업무 부담은 대폭 감소하고 학생의 편의성이 증가할 것을 기대.

### Commit Message Guide

- Feat: (내용) → 새로운 기능 추가
- Fix: (내용) → 버그 수정
- Design: (내용) → UI 디자인 변경 ex. CSS
- Test: (내용) → 테스트 코드
- Chore: (내용) → 사소한 수정이나 빌드 업데이트
- Rename: (파일) → 파일이나 폴더명 수정만 한 경우
- Remove: (파일) → 파일 삭제만 한 경우
